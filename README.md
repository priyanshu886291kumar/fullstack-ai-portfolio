## ✨ Features
* 🌐 **Full-Stack & Real-Time Focus:** Showcasing ConvoCam (WebSockets + WebRTC P2P Video), Emotion-Based Music Streaming, and AI News Curator.
* 📐 **Interactive Real-Time Architecture Blueprint:** 4-stage WebSockets signaling, WebRTC P2P streaming, and Gemini AI inference pipeline.
* 💻 **Interactive Full-Stack CLI Terminal:** Functional Unix console supporting commands (`whoami`, `skills`, `projects`, `experience`, `education`, `contact`, `help`).
* 📊 **Codolio Unified DSA Tracking:** Highlighting 600+ solved DSA problems across LeetCode & GeeksforGeeks, Flipkart GRID finalist milestones, and JEE AIR 26k.
* ⚡ **Ultra-Fast Performance:** Built on Vite with responsive glassmorphism and cursor-tracking radial spotlights.

    ├── main.jsx               # React entry point
    ├── App.jsx                # Main layout assembler
